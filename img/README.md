# 초상 그림 넣는 곳

이 폴더에 아래 이름 그대로 배경이 투명한 WEBP를 올리면, 안내서의 인물 장에 바로 나타납니다.
WEBP가 없으면 같은 이름의 PNG를 찾고, 둘 다 없으면 옅은 실루엣이 대신 보입니다.

| 파일 이름 | 인물 | 권장 비율 |
| --- | --- | --- |
| `yohyeon.webp` | 요현 | 1:2 전신 (예: 800×1600) |
| `ryu-seojin.webp` | 류서진 | 3:4 상반신 (예: 900×1200) |
| `ju-aryeong.webp` | 주아령 | 3:4 상반신 |
| `namgung-hwi.webp` | 남궁휘 | 3:4 상반신 |
| `kwon-munhyeok.webp` | 권문혁 | 3:4 상반신 |
| `yun-segwang.webp` | 윤세광 | 3:4 상반신 |

인물은 그림 가운데에, 발끝(상반신은 가슴 아래)이 아래 가장자리에 닿게 두면 가장 자연스럽습니다.
