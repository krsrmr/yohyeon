# 초상 그림 넣는 곳

이 폴더에 아래 이름 그대로 배경이 투명한 PNG를 올리면, 안내서의 인물 장에 바로 나타납니다.
파일이 없는 동안에는 옅은 실루엣이 대신 보입니다.

| 파일 이름 | 인물 | 권장 비율 |
| --- | --- | --- |
| `yohyeon.png` | 요현 | 1:2 전신 (예: 800×1600) |
| `ryu-seojin.png` | 류서진 | 3:4 상반신 (예: 900×1200) |
| `ju-aryeong.png` | 주아령 | 3:4 상반신 |
| `namgung-hwi.png` | 남궁휘 | 3:4 상반신 |
| `kwon-munhyeok.png` | 권문혁 | 3:4 상반신 |
| `yun-segwang.png` | 윤세광 | 3:4 상반신 |

인물은 그림 가운데에, 발끝(상반신은 가슴 아래)이 아래 가장자리에 닿게 두면 가장 자연스럽습니다.
